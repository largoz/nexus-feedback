# Nexus — звіти про проблеми

Сюди Nexus надсилає звіти користувачів: виділені повідомлення з чату, коментар,
логи та інформацію про систему.

**Кожен звіт зашифрований ключем розробника** (формат [age](https://age-encryption.org)).
Прочитати його може лише розробник. Публічна тут тільки **назва** issue —
не пишіть у неї нічого приватного.

## Як надіслати

У Nexus: виділіть повідомлення в чаті (або натисніть «Повідомити» біля помилки)
→ «Надіслати відгук» → увійдіть через GitHub. Без GitHub звіт можна зберегти
файлом `.age` і надіслати будь-яким способом.

Перед відправкою Nexus показує, що саме піде, і вирізає секрети
(токени, ключі, паролі).

## Для розробника

```sh
nexus feedback open 12          # або URL issue, або файл .age
```

---

*Problem reports from Nexus. Each report is encrypted to the maintainer's key;
only the issue title is public.*
